# nakama-voice (archived)

Early Go prototype of a voice module for Nakama (March 2026). It was superseded by
[aurix-voice/aurix](https://github.com/aurix-voice/aurix), a standalone open-source voice platform
with native and WebRTC transports, spatial audio, E2EE and SDKs for Unity, Unreal, Godot and Web.
Kept read-only for reference; nothing here is maintained.
